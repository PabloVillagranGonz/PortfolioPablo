Descripción general

AulasFree es una aplicación desarrollada para la gestión digital de aulas en un conservatorio. Permite a secretaría controlar en tiempo real la ocupación de espacios, gestionar reservas de alumnos y consultar el historial completo de uso.

El sistema está construido con una arquitectura moderna basada en:

Flutter Spring Boot MySQL JWT Ready REST API

Funcionalidades principales

Gestión en tiempo real

  • Visualización del estado de todas las aulas.
  • Indicadores claros de disponibilidad y ocupación.
  • Información detallada de cada reserva activa.

Control automático

  • Cierre automático de reservas vencidas mediante tareas programadas (@Scheduled).
  • Actualización automática del estado del aula en backend.
  • Barra de progreso y cuenta atrás sincronizada en tiempo real.

Validaciones y control de reglas de negocio

  • Restricción de una única reserva activa por alumno.
  • Control de duración máxima permitida.
  • Gestión estructurada de errores con códigos HTTP adecuados (409, 400…).

Historial y trazabilidad

  • Registro persistente de todas las reservas.
  • Filtros por alumno, fecha y año.
  • Estructura preparada para generación de estadísticas avanzadas.

Galería — Vista Secretaría

Interfaz de secretaría: gestión en tiempo real del estado de aulas, creación de reservas para alumnos y control de reservas activas con cuenta atrás.

Galería — Vista Alumno

Interfaz del alumno: consulta en solo lectura del estado de las aulas. Puede ver la disponibilidad y ocupación, pero no puede crear ni eliminar reservas.
