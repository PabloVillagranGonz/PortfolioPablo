PentaNet

Resumen

PentaNet es una aplicación full-stack de gestión académica orientada a conservatorios, escuelas de música y centros formativos. Ha sido desarrollada como un proyecto real, con frontend en Flutter y backend en Spring Boot, incluyendo autenticación segura, control de roles y comunicación mediante API REST.

Objetivo del proyecto

Desarrollar una infraestructura digital capaz de gestionar la complejidad de un centro educativo moderno. El sistema permite la convivencia de administradores, profesores, alumnos y personal de secretaría, cada uno con flujos de trabajo optimizados y permisos granulares, garantizando la integridad de los datos y la fluidez en la comunicación.

Gestión de usuarios y roles

  • Administrador: Control total sobre centros, cursos, asignaturas, horarios, aulas y usuarios.
  • Secretaría: Gestión especializada de la ocupación de espacios y reservas de aulas en tiempo real.
  • Profesor: Seguimiento académico, gestión de calificaciones, faltas y comunicación con alumnos.
  • Alumno: Consulta de horarios, expedientes, notas y reserva de espacios de estudio.

La asignación es completamente automática: cuando un alumno pertenece a un curso, hereda directamente asignaturas, horarios y profesores, sin configuraciones manuales adicionales.

Tecnologías & stack

Flutter Dart Java Spring Boot MySQL JWT REST API

Arquitectura

  • Backend: Controladores → Servicios → Repositorios (Spring Boot).
  • Frontend: Controllers / Services / Providers (Flutter).
  • Separación estricta entre lógica de negocio, UI y acceso a datos.

Sistema de mensajería interna

  • Bandeja de entrada y enviados
  • Mensajes leídos y no leídos
  • Eliminación y contador de mensajes
  • Gestión completa desde backend con usuario autenticado

Seguridad y autenticación

  • Login con usuario y contraseña
  • Autenticación mediante JWT
  • Protección de endpoints por rol (Spring Security)
  • Validación de permisos en backend

Control de acceso por roles

  • Las vistas se renderizan dinámicamente según el rol autenticado.
  • Los endpoints sensibles están protegidos mediante Spring Security.
  • El frontend no decide permisos: el backend valida cada acción.

Galería — Vista Alumno

Interfaz del alumno: mensajería interna, bandeja de entrada/salida, perfil personal, asignaturas, horarios y datos del centro.

Galería — Vista profesor

Interfaz del profesor: mensajería interna, bandeja de entrada/salida, perfil personal, asignaturas, horarios, asignar notas, asignar faltas y datos del centro.

Galería — Vista Administrador

Interfaz del administrador: gestión completa del sistema académico, usuarios, centros, cursos, asignaturas, aulas y horarios.

Galería — Vista Secretaría (Gestión de Aulas)

Interfaz de secretaría enfocada en la optimización de espacios. Incluye el motor de reservas en tiempo real (anteriormente Aulas Free), permitiendo el control dinámico de la ocupación, historial de usos y gestión de inventario de aulas.

Aprendizajes clave

  • Diseño de APIs REST limpias y mantenibles.
  • Control de roles y permisos en aplicaciones reales.
  • Integración completa frontend ↔ backend.
  • Gestión de estado y arquitectura en Flutter.
  • Pensar en escalabilidad y mantenimiento desde el diseño.
