La Liga

Web app para grupo musical — React, Tailwind CSS y Radix UI

Ver repositorio Ver sitio web Volver al portfolio

Descripción general

La Liga es la web oficial del grupo musical, reescrita completamente como una Single Page Application (SPA) moderna. Diseñada para presentar su estilo, anunciar actuaciones y facilitar el contacto con una experiencia de usuario fluida y rápida.

Resumen del proyecto

Desarrollada con React y estilizada mediante Tailwind CSS, la aplicación utiliza componentes accesibles de Radix UI para ofrecer una interfaz interactiva y robusta.

Diseño

Diseño completamente responsive y moderno, priorizando la claridad, el ritmo visual y un enfoque mobile-first. Se incluyen animaciones fluidas y soporte para temas visuales.

React Tailwind JavaScript Responsive

Desarrollo

Arquitectura basada en componentes reutilizables, gestión de dependencias moderna y optimización del rendimiento. Se ha puesto especial foco en la accesibilidad y en la creación de una experiencia interactiva sin recargas de página.

Lecciones aprendidas

  • Integración de librerías de UI modernas como Radix y shadcn/ui.
  • Gestión del estado en aplicaciones React complejas.
  • Uso avanzado de utilidades de Tailwind para diseños responsive y animaciones.
