La Liga

Página web para grupo musical — HTML, CSS y EmailJS

Ver repositorio Ver sitio web Volver al portfolio

Descripción general

La Liga es la web oficial del grupo musical, diseñada para presentar su estilo, anunciar actuaciones y facilitar el contacto con sus seguidores. Es una web estática rápida, ligera y totalmente responsive.

Resumen del proyecto

Diseñada en HTML & CSS con una estructura modular y soporte para EmailJS, permitiendo que los visitantes envíen mensajes sin necesidad de backend. Incluye secciones: inicio, biografía, conciertos, galería y contacto.

Diseño

Inspirado en un estilo moderno y visual, priorizando claridad, ritmo visual y un enfoque mobile-first. Se incluyen CTAs claros y una experiencia de navegación fluida.

HTML CSS JavaScript EmailJS Responsive

Desarrollo

Desarrollo completo desde cero: estructura semántica, estilos propios, integración de galería, animaciones ligeras y manejo del formulario mediante EmailJS.

Lecciones aprendidas

  • Optimizar imágenes para reducir tiempos de carga.
  • Integración de formularios sin backend práctico y rápido con EmailJS.
  • Diseño responsive real probado en varios dispositivos.
